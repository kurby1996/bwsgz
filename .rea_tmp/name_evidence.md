# 中文姓名及字体证据

目标为本地 `霸王三国志-免登录版/roms/三國志II-霸王三国志.md`。以下为 ROM 静态字模证据；未通过模拟器 UI 验证改名。

## 字库定位

原字体展开函数在 `0x4554`，汉化补丁从 `0x4560` 跳到 `0x5E800`：

- 字码小于 `0x831E`：`0x55896 + (code - 0x8140) * 32`
- 字码从 `0x831E` 至 `0x841D`：`0x5A000 + (code - 0x831E) * 32`
- 字码大于等于 `0x841E`：`0xFD000 + (code - 0x841E) * 32`

每字 32 字节 1bpp，由 TL/TR/BL/BR 四个 8×8 tile 组成。`0x4598` 至 `0x4600` 将每个 1bpp 位展开为 4bpp 的 0 或 F 像素。

## 姓名

`0x4C8D4 + name_id * 16`，共 352 名，前 7 字节是最多 3 个双字节字码加零结束符。剩余 9 字节保持原样。

`.rea_tmp/name_names_0.png` 为本 ROM 所有姓名的实际字模合成图，`name_uncertain.png` 为若干歧义姓名放大图。`name_transcription.txt` 为逐项简体转录。所有重复字码已做全表一致性检查，修正了孙权、审荣、张休等易混字。游戏字库/文本本身存在与惯用历史姓名不一致的写法，模块按实际字模转录，未擅自校正为历史姓名。

`trainer/names.json` 包含 383 个姓名字码映射；`trainer/names.py` 额外加入已字模确认的能力与军事标签字码。显示用简体，编码可接受常见繁体别名。未知字符明确拒绝，未知字码显示十六进制占位，不能把 GBK/Shift-JIS 直接写入 ROM。

## 属性标签

`.rea_tmp/name_labels.png` 展开了实际文本：

- `0x428CC`：智力、武力、魅力、年龄。对应调用方的武将记录 `+6/+7/+8` 为智力/武力/魅力。
- `0x428FC`：忠诚、武装、训练、士兵。结合调用方，`+0x12` 确认为训练。

## 验证

`python .rea_tmp/name_test.py` 检查 352 个姓名读取/改名往返、姓名前 7 字节之外保持不变、空名/超长名/非法字拒绝、简繁体刘备编码一致、字模尺寸。全部通过。该验证是静态字节验证，未建立模拟器实际改名运行结果。
